# Impeccable Design Context: Box Office

## Design Concept & Philosophy
- **Concept:** "Box Office." Event paper, ink, and one stamp-red accent. Calm, dense, editorial, and fast to scan.
- **Negative Constraints (Strictly Prohibited):**
  - NO Inter or Poppins typography.
  - NO purple-to-blue gradients.
  - NO cards inside cards.
  - NO gray text on colored backgrounds.
  - NO centered hero with two identical buttons.
  - NO glassmorphism or backdrop blur gimmicks.
  - NO emoji icons.
  - NO three identical rounded feature cards.
  - NO invented/fake stats, fictitious logos, or placeholder testimonials. Public numbers MUST come from the database or not appear at all.

## Palette & CSS Variables (tokens.css)
*Only these exact color variables are allowed:*
- `--color-paper`: `#F4EFE6` (base paper background)
- `--color-surface`: `#FBF8F2` (inputs, table headers, elevated rows)
- `--color-ink`: `#17140F` (primary text, borders, high contrast)
- `--color-muted`: `#6B655A` (secondary captions, metadata, subtle borders)
- `--color-rule`: `#D8D0C0` (hairline dividers, 1px borders)
- `--color-accent`: `#D9411E` (stamp-red accent: primary action buttons, active navigation indicator, ticket stub accent edge)
- `--color-success`: `#2F5D3A` (confirmed, paid, checked-in badges)
- `--color-pending`: `#B7791F` (draft, pending payment, awaiting check-in badges)
- `--color-danger`: `#A3261A` (cancelled, failed, refunded, destructive actions)

## Accent Rule
Use `--color-accent` sparingly:
1. Primary actions (e.g. "Register Tickets", "Publish Event").
2. Active navigation link marker.
3. The perforated Ticket Stub edge.

## Typography
- **Headings & Page Titles:** `Newsreader`, serif, with italic styling for editorial page titles and section headers.
- **UI Elements, Body, Navigation, Forms:** `Schibsted Grotesk`, sans-serif.
- **Numbers, Currencies, Timestamps & Codes:** Tabular numbers (`font-variant-numeric: tabular-nums`) with monospace fallback (`JetBrains Mono` / `Courier New`).
- Maximum two families loaded from Google Fonts with standard system fallbacks.

## Memorable Signature Element: `<Stub />` Component
- Ticket stub aesthetic with a perforated dashed line divider (`border-right: 2px dashed var(--color-rule)`).
- Notched semi-circular corner cutouts (CSS radial-gradient or clean clip-path / pseudo-elements).
- Prominent `registrationCode` styled in small caps / uppercase tracking.
- Reused in three critical user touchpoints:
  1. Registration checkout success screen.
  2. Attendee "My Tickets" collection.
  3. Organizer "Registrations & Check-In" verification modal.

## Layout & Spatial Geometry
- Flat horizontal rows separated by 1px hairline rules (`var(--color-rule)`) instead of floating rounded cards.
- Left-aligned, asymmetrical editorial layouts.
- Header top-bar featuring a text-only wordmark ("BOX OFFICE / EMS") — NO generic logo graphics.
- Generous, proportional spacing scale based on 4px/8px increments.
- 1px borders, minimal border-radius (2px to 4px maximum).
- Flat surface design: NO box shadows except for an accessible high-contrast focus ring (`outline: 2px solid var(--color-accent); outline-offset: 2px;`).
- 44px minimum touch targets on all interactive buttons and inputs.
- WCAG AA contrast compliance across all text and interactive states.
- Mobile-first responsive down to 360px viewport width (data tables transform smoothly into stacked horizontal records).
- Respect `prefers-reduced-motion` media queries; limit state transitions to 150–200ms ease.

## Tech Stack Rules
- Plain CSS with CSS Custom Properties in `tokens.css` and `base.css` (NO Tailwind CSS, NO UI kits).
- Icons: `lucide-react` used sparingly with a consistent 1.5 stroke width.
- Charts: Pure SVG and CSS bar charts only (NO external chart libraries).
